# MAPSCART | A Think Trend

MAPSCART is a responsive, full-stack e-commerce web application designed for a premium jewelry boutique. Built using the Django web framework, the platform provides a seamless shopping experience for curated collections of earrings, necklaces, rings, and bracelets.

The application emphasizes an elegant, modern user interface alongside robust backend functionality to handle product displays, user sessions, and shopping cart operations.

## 🌟 Key Features

*   **Dynamic Storefront:** Renders the latest arrivals and specific product collections directly from the backend database.
*   **User Authentication:** Secure login, logout, and personalized account dashboards for order tracking.
*   **Interactive Shopping Cart:** Real-time cart badge updates and cart detail management for authenticated and guest users.
*   **Responsive UI:** A fully responsive, mobile-friendly design utilizing custom CSS variables, Google Fonts (Cormorant Garamond, Jost, Cinzel), and FontAwesome icons.

## 💻 Tech Stack

*   **Backend:** Python, Django
*   **Database:** SQLite (Development) / PostgreSQL (Production)
*   **Frontend:** HTML5, CSS3, JavaScript, Django Template Language (DTL)
